# Week 1: Game Feature Planning and Design Document

## 🎯 Objective
The goal of this week was to conceptualize and plan a new game mechanic. This phase emphasizes the importance of a structured approach to game design before any code is written.

## 📝 Feature Overview: Dynamic Stamina & Dodge System
This folder contains the official Game Design Document (GDD) for an Action RPG stamina management system. The mechanic requires players to balance offensive attacks with defensive dodge-rolls, using a secondary resource bar that regenerates over time.

### Key Deliverables:
* **Mechanics Breakdown:** Defined maximum stamina, consumption costs, and regeneration rates.
* **UX/UI Guidelines:** Outlined exhaustion state triggers and visual feedback.
* **Pseudocode & Flow:** Mapped out the internal logic for the real-time update loop.

**Included File:** `Week_1_Design.docx`
